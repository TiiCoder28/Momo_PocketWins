## Working product statement

**PocketWins is a personalized behavioural finance companion inside MoMo that learns from a user's own spending history and goals, recognizes improving habits, and helps them turn positive everyday choices into savings for their future self.**

## Core product loop

**Plan → Spend → Reflect → Recognise → Pay Yourself → Save → Review → Repeat**

These documents are intentionally living documents and should evolve as API feasibility, product research, and hackathon requirements become clearer.
