# PocketWins

**PocketWins** is a MoMo Mini App concept by **Binary Bandit** for the **MoMo Mini App Hackathon 2026**.

> **Turn small everyday wins into savings.**

PocketWins is a personalized behavioural finance companion designed to help users understand their spending patterns, improve financial habits over time, and reward positive everyday choices by paying their future selves.

Rather than acting as a generic budgeting chatbot, PocketWins builds a longitudinal picture of each user's own behaviour. It looks for patterns, progress, triggers, and trends, then uses that context to offer increasingly personalized guidance.

## Core product loop

**Plan → Spend → Reflect → Recognise → Pay Yourself → Save → Review → Repeat**
